Architecture CORBA

Ce projet utilise CORBA (Common Object Request Broker Architecture) pour la communication distribuée entre le client Spring Boot et le serveur de services PDF.

1
Client Web
Le navigateur envoie une requête HTTP
2
Spring Boot (ORB Client)
Traduction HTTP → requête CORBA via l'ORB
3
POA + Servant CORBA
Dispatching de la requête vers PDFServiceImpl
4
Apache PDFBox
